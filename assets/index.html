Duplicate theorems

Groups of theorems whose statements are the same type up to isomorphism (reordered or curried binders, swapped sides, equivalent connectives), each proved separately.

i Probable API pairs are duplicates that look written twice on purpose rather than by accident. A pair counts as one if:
  • the two are declared in one module within 12 lines of each other, or are recognised twins: both orientations of an = / ↔ / ≠ (A_eq_B / B_eq_A), primed variants, contains / mem twins, names differing by a symmetric word pair;
  • they are a reordered or re-oriented pair in one file where one side is @[simp];
  • one side lives in an internal namespace (Internal, Simproc, Grind, Omega, Tactic, Meta, …).
Hiding them leaves the duplicates most likely to be accidental.
